# Exemplos para entrevista técnica

Estes programas enfatizam pontos que costumam ser discutidos em entrevistas:

- processamento de tabelas e algoritmo de ordenação;
- comparação de dados para conciliação bancária;
- cálculo de financiamento e geração de cronograma de parcelas.

Todos são executados pelo `build.ps1` localizado na raiz do repositório.
